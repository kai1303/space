# Slack-style mentions in Space

Checked 2026-11-03 against Slack's [mention guide](https://slack.com/help/articles/205240127-Use-mentions-in-Slack), [broadcast rules](https://slack.com/help/articles/202009646-Notify-a-channel-or-workspace), and [developer formatting reference](https://docs.slack.dev/messaging/formatting-message-text/#mentioning-users). The earlier retained `SHZE` client module also contains `maybeTriggerMentionAutocomplete`, the `slackmention` format, and validation of member, broadcast and user-group IDs. That is static shipped-client evidence; this change did not send Slack messages or test Slack notification delivery.

Space stores `{ kind, id, label }` on a readable rich-text operation such as `@Jamie Chen`. The label is a snapshot, while the ID is authoritative. The server resolves the current label when sending, checks workspace/channel membership and agent grants, and opens profiles using the ID. Existing plain text tags are retained for compatibility, not automatically assigned human identities.

Typing `@` or using the mention button searches members and available agent installations. Enter/Tab selects before Enter sends; arrows navigate; Escape dismisses. Identity spans are protected from partial backspace/delete. The picker restores the editor selection and ignores email addresses, code, links and quoted lines. The gallery uses explicitly synthetic people and agents; it does not notify anyone or run an agent.

User mentions create one durable in-app activity item per recipient/message in the message transaction, so retries cannot duplicate notifications. Public non-members can receive activity and join before opening the source. Private non-members are not notified or granted access. Activity access is checked again after revocation. Direct mentions work in threads; broadcasts do not notify from thread replies.

`@here` uses members' Space presence setting, `@channel` includes active channel members regardless of presence, and `@everyone` is limited to the workspace's stable general-channel identity. Migration 025 initializes that identity from an existing public general channel; a trigger captures it when a public general channel is created. Renaming the channel preserves its identity. Admins can restrict broadcasts to owners/admins. Sending a broadcast to six or more members requires confirmation in both the UI and API. Notification pausing leaves new activity silent rather than increasing its attention count.

Agent references route through the existing Navigator and approval/grant checks using installation IDs. Human and broadcast references cannot invoke an agent sharing their name. Code/quoted references do not invoke agents.

The inbox refreshes on relevant current-channel message events, window focus, and a ten-second interval for other channels. Desktop/mobile push and user-group mentions are not implemented. Plain-text-only transports do not offer semantic mention completion. Mention display names in saved message bodies remain snapshots; clicking opens the current profile.

Validation: contract tests cover reference validation and literal/code exclusions; UI tests cover selection, keyboard handling, confirmation, deletion, channel changes, clickable/self mentions, malformed activity, revocation, profile resolution and read state. Database tests cover canonical identities, scoped directory search, recipient deduplication, private access, broadcast permission/presence/thread/pause behavior, server confirmation and agent routing after renames. Migration 025 was applied to the local development database without applying unrelated pending migrations. Affected packages typecheck; repository-wide checks may include concurrent work outside this change.

Final local checks: 106 focused tests passed (35 chat, 23 composer/inbox, 25 shared UI/emoji, and 23 contracts/database/Navigator); affected package and test-project typechecks and the web production build passed. The UI/emoji suite uses `NODE_OPTIONS=--no-experimental-webstorage` with this machine's Node 25 to avoid its global storage object overriding jsdom's localStorage. Browser verification selected a person with Enter, sent a clickable reference, and opened the profile in the synthetic gallery.
