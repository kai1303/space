# Saved in Slack desktop, November 14, 2026

Observed in the signed-in Slack web client. A temporary bookmark on an existing
message was removed after inspection. No message was posted.

- Home shortcuts in order: Threads, Huddles, Drafts & sent, Saved, Directories.
- The empty screen had a 49 px header with an 18 px title and no tabs. A centered
  illustration (157 × 140 px) sat above “Nothing saved yet” and “Save a message to keep it here.”
- The message menu had “Add to saved”. The original message then showed “Saved for later · View Saved”.
- A bookmark made today on an older message showed today's date. The 65 px row
  showed the message preview above the author and source, with an avatar on the left.
- Selecting the row opened the conversation alongside the list. Hover actions
  included Clear and More actions; the latter contained Move to to-dos, Open in
  Home, Open in split view, Open in new window, and Clear. Clearing offered Undo.
- Clean up contained both bulk actions: move to To-dos and remove all. A separate
  migration banner explained how Slack divided the old Later feature between Saved
  and To-dos. Space shows the same dismissible banner layout and actions with copy about its own Saved and To-dos features.

The populated view uses Slack’s banner artwork. The empty bookmark is a Space adaptation. Space uses its own conversation renderer, confirmation copy and
Motion transitions. Rows are sorted by bookmark time, with message ID as a
tie-breaker. Screenshots of Space come from an isolated signed-in browser test.
