# AG-UI implementation plan

**Goal:** Render streaming and durable structured agent responses in Space.

**Architecture:** A configurable official AG-UI HTTP client maps events into Space's existing execution envelope with an accumulated response. The database saves it with the completed message; React renders it through existing UI primitives.

**Tech stack:** TypeScript, @ag-ui/client/core 1.0.3, PostgreSQL JSONB, React, react-markdown and remark-gfm.
