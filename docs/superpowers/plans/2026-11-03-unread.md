# Per-user realtime unread implementation plan

**Goal:** Persist independent channel read positions, update unread counts live across channels and devices, and clear them only when the latest channel messages are visible in a focused window.

**Architecture:** Store one monotonic cursor per channel membership. Derive counts from immutable main-timeline root message sequences, excluding the reader's own messages. Thread replies use the existing mention inbox rather than the channel badge. Reuse the transactional chat outbox for workspace socket snapshots; reconnect and focus fetch authoritative summaries through the ordered socket stream. Existing history starts read when the migration runs or a user joins a channel.

**Stack:** PostgreSQL, Drizzle SQL, Fastify, Socket.IO, React, node:test and Vitest.
