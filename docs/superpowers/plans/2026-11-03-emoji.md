# Emoji support implementation plan

Goal: bring Slack's standard Unicode emoji workflow to Space using one shared catalog and picker.

- [x] Record live Slack picker behavior and analyze captured shipped modules with REA CLI.
- [x] Add catalog-backed search, aliases, categories, skin tones, and browser-local recent choices; reuse the existing floating Popover and Space tokens.
- [x] Integrate the picker into rich/plain composers, message reactions, and status. Support shortcode suggestions and conversion without changing code or links.
- [x] Persist per-user reactions with idempotent add/remove, channel authorization, durable realtime events, and history hydration.
- [x] Test search/tones/shortcodes, composer selection/keyboard, picker focus, persistence/access control/replay; run UI/web checks and inspect the browser.

Workspace custom image uploads/aliases and GIFs need their own asset lifecycle and are outside this Unicode implementation. Slack observation, REA static findings, and Space adaptations will be identified separately in the research note.
