# Slack-style mentions

Approved scope: identity-backed @user, @agent, @here, @channel, and @everyone, with searchable keyboard completion, clickable rendering, server authorization, and in-app mention activity.

- Extend rich-document attributes with a validated mention reference and preserve plain text for transport/search/accessibility. Resolve current labels on send; never infer identity from a duplicate display name.
- Add channel-scoped member/installed-agent search. Public channels can suggest workspace members; private channels only expose channel members. Broadcast suggestions follow role restrictions and the workspace's stable general-channel ID.
- Persist one notification per human recipient/message in the message transaction. Ignore self and literal/code/quoted examples; direct mentions work in threads, broadcasts do not. Paused attention is silent in the inbox. Replays/retries cannot duplicate activity.
- Keep existing approved agent execution and grants. Semantic agent IDs route directly; human and broadcast mentions cannot trigger an agent with the same name.
- Reuse the shared composer, dialog, popover and profile patterns. Share completion in channel/thread composers; Enter/Tab chooses before Enter sends; Escape cancels; IME remains intact.
- Add a Mentions inbox with unread counts, read state, permission-checked links, pause controls, and admin broadcast settings. No external push provider is introduced.
- Verify contracts, composer keyboard/selection, identity rendering, directory authorization, recipient deduplication, broadcasts, private-access revocation, and agent routing. Preserve concurrent emoji/connector edits.
