# Space changelog

## Since v1.0.0 · November 14, 2026

**On main** covers the 148 commits from V1 on November 10 (`29b45bd`) through `6b37add` on November 14. **Still local** covers uncommitted changes in the Space checkout at the time of review. Status describes where the code lives. Production deployment, app-store availability, and runtime verification are outside this snapshot. [Compare V1 with main](https://github.com/kai1303/space/compare/v1.0.0...6b37add)

### On main

#### Chat, channels, and search

- **Scheduled messages.** Choose a delivery time in the composer, including for messages with attachments. Open **Drafts & sent → Scheduled** to change the time, send immediately, or cancel. [Composer](https://github.com/kai1303/space/commit/883044d) · [Delivery](https://github.com/kai1303/space/commit/05decc3)
- **Shared pins and channel tabs.** Pin a message for everyone in the channel. Browse shared files and posted links, jump to a link’s source message, and customize which channel tabs appear and in what order. [Channel tabs and pins](https://github.com/kai1303/space/commit/1ed0050)
- **Split-view channels and channel actions.** Open a second channel alongside the first. The sidebar menu also gives access to channel details and lets you copy a channel name, channel link, or huddle link. [Channel menu](https://github.com/kai1303/space/commit/1320993)
- **Per-channel notifications.** Choose all new posts, mentions only, or mute and hide. Temporarily mute a channel for an hour or until tomorrow, resume notifications early, or open its advanced preferences. [Notification controls](https://github.com/kai1303/space/commit/1320993)
- **Channel agents and apps.** Channel details lists connected agents and apps. Search available agents and skills, grant a skill to the channel, or start connecting another agent. [Channel agent picker](https://github.com/kai1303/space/blob/6b37add/apps/web/src/features/channels/ChannelAgents.tsx)
- **Search beside the conversation.** Channel search keeps a resizable results pane open as you inspect messages and replies. The final search term supports prefix matching, and opening search shows recent conversations. [Channel search](https://github.com/kai1303/space/commit/1ed0050) · [Recent conversations](https://github.com/kai1303/space/commit/3791a98)
- **Pending sends and action feedback.** Pending chat sends survive a reload. Message and file actions show confirmation or error toasts, live replies animate into place, and long links take up less room in chat. [Pending sends](https://github.com/kai1303/space/commit/6eedb36) · [Toasts](https://github.com/kai1303/space/commit/3156911) · [Chat links](https://github.com/kai1303/space/commit/a35d5ba)

#### Files and Office

- **Attachment composer.** Preview selected files, see upload progress and failures per file, and press Send before uploads finish. The message waits for its attachments. The file picker can reuse a shared file and filter by type or ownership. [Uploads](https://github.com/kai1303/space/commit/c933918) · [File picker](https://github.com/kai1303/space/blob/6b37add/apps/web/src/features/files/AttachFileDialog.tsx)
- **Attachment galleries and file details.** Images posted together form a gallery. Open the original to pan, zoom, or rotate it. Cards show file type and size, and uploaders can edit the filename and description. [Gallery and viewer](https://github.com/kai1303/space/commit/c933918)
- **Office previews.** With ONLYOFFICE configured, open Word documents, spreadsheets, presentations, and their OpenDocument equivalents from chat. Cards can show the first page of the saved revision. Markdown attachments render in the text viewer. [Preview formats and setup](https://github.com/kai1303/space/blob/6b37add/docs/architecture/assets.md)
- **Collaborative Office editing.** Uploaders can edit a channel document and enable **Channel editing** for members who can post there. Co-editors see one another’s changes. Space saves the working copy after the last editor closes and keeps the original upload available. [Collaborative editing](https://github.com/kai1303/space/commit/be8999f)
- **Ask Space AI in a document.** In Space Desktop, select text in a DOCX or ODT to ask the local Codex CLI a question or request a rewrite. If the selection changes during drafting, the editor shows the proposal for review. [Selection editing](https://github.com/kai1303/space/commit/a35d5ba)

#### Agent sessions

- **Files in agent turns.** Attach files to a session message and pass supported content to the paired Codex, Claude, or Kiro connector. PDF page reading and citations are listed under **Still local** below. [Session attachments](https://github.com/kai1303/space/commit/659aa37)
- **Follow-up queue.** Queue input while an agent works. Preview, edit, reorder, or remove waiting messages and resume a paused queue. [Queue controls](https://github.com/kai1303/space/blob/6b37add/apps/web/src/features/agents/SessionQueue.tsx)
- **Live steering.** The owner of a supported running session can send an instruction into the current turn, including from the queue. The composer remembers the preferred follow-up action and exposes both actions by keyboard. [Steering](https://github.com/kai1303/space/commit/6b37add)
- **Voice dictation.** Record a spoken follow-up, transcribe it on the device, and insert the text into the composer for editing or sending. [Dictation](https://github.com/kai1303/space/blob/6b37add/apps/web/src/features/agents/AgentDictation.tsx)
- **Codex session titles and links.** Space synchronizes Codex session titles. Chat shows separate links for a message’s replies and its associated agent session. Agent cards also use a consistent layout and clearer status indicators. [Title sync](https://github.com/kai1303/space/commit/6b37add) · [Chat links](https://github.com/kai1303/space/blob/6b37add/README.md) · [Agent badges](https://github.com/kai1303/space/commit/2e580a0)
- **Composer previews.** The committed composer previews goal controls and model and reasoning-effort selection. Provider-backed settings and persistent goals are local additions. [Composer at the main snapshot](https://github.com/kai1303/space/blob/6b37add/apps/web/src/features/agents/AgentSessionComposer.tsx)

#### Knowledge and Memory

- **Workspace knowledge plugins.** Connect an external knowledge system, test its connection, and grant its search or lookup tools to an agent. The built-in people directory answers membership questions. The optional PostgreSQL provider searches runbooks by keyword and meaning, follows service ownership, and returns citations subject to audience access. [Plugin interface](https://github.com/kai1303/space/blob/6b37add/docs/architecture/knowledge-plugins.md)
- **Search across knowledge sources.** The PostgreSQL provider can index opted-in channel discussions, Markdown files, and knowledge notes. It can find related knowledge through shared evidence threads and link back to sources. [Provider setup](https://github.com/kai1303/space/blob/6b37add/apps/mcp-gateway/providers/pg-knowledge/README.md)
- **Channel knowledge notes.** Enable notes per channel. Authorized agents can save decisions and procedures with evidence, revise a note under the same title, and search its contents. Agents see recent note titles in task context. [Knowledge notes](https://github.com/kai1303/space/commit/3dce354)
- **Layered memory.** Agents receive context at channel, thread, and session scope. The optional graph database ranks messages by meaning. Space falls back to recency when that database is absent and rechecks access when reading the source text. [Layered memory](https://github.com/kai1303/space/commit/a8b2b87)
- **Interactive memory graphs.** Explore memory in a channel tab or across joined channels under **Agents & tools → Memory**. Expand nodes, drag or zoom the graph, navigate by keyboard, and inspect supporting details. Channel nodes show the topic and description, with frequently discussed topics when the topic is empty. [Workspace graph](https://github.com/kai1303/space/commit/6468667) · [Channel topics](https://github.com/kai1303/space/commit/12e090e)
- **Automatic topic and fact extraction.** A configured local model extracts topics and facts from threads and records the supporting message revisions. Edits, deletions, archives, and restores update which evidence can appear. [Extraction](https://github.com/kai1303/space/commit/ff4e2c9) · [Evidence consistency](https://github.com/kai1303/space/commit/822ea15)

#### Mobile, desktop, and project updates

- **iOS and Android app shells.** Capacitor packages the web app for both platforms with native keyboard, status bar, splash screen, back-button handling, and Space icons. Release builds require HTTPS. The earlier Expo prototype was retired during this interval. [Capacitor shell](https://github.com/kai1303/space/commit/a4ea073) · [Native integration](https://github.com/kai1303/space/commit/9ed95b0)
- **Phone navigation and gestures.** Home opens to the conversation list with collapsing shortcuts, a floating compose button, and bottom tabs. Conversations, threads, and sessions get back navigation. Swipe from the left edge to go back and long-press a message for actions. Search opens full-screen, Activity has touch-friendly filters, and the composer fits the keyboard and safe areas. [Phone layout](https://github.com/kai1303/space/commit/cad140c) · [Swipe back](https://github.com/kai1303/space/commit/a62df0a) · [Touch actions](https://github.com/kai1303/space/commit/6aeadcb)
- **Office and browser tabs beside chat on macOS.** The existing browser panel now hosts Office documents in the same tab strip. Switch between a document, a website, and chat while preserving the editor and split width. [Desktop workspace panel](https://github.com/kai1303/space/commit/be8999f)
- **Reply suggestions and huddles.** Reply suggestions now use xAI with `XAI_API_KEY`. The web app loads LiveKit when someone joins a huddle. [Reply provider](https://github.com/kai1303/space/commit/8dd0235) · [Huddle loading](https://github.com/kai1303/space/commit/74bcac1)
- **Storage and maintenance.** PostgreSQL now holds built-in Markdown channel memory. A change-data-capture reader builds and reconciles the optional knowledge graph. Scheduled sends use broker-held deadlines, and `nats:prune` identifies and removes streams left by deleted database schemas. [Memory storage](https://github.com/kai1303/space/commit/822ea15) · [Graph setup](https://github.com/kai1303/space/commit/fc9f6a8) · [Stream cleanup](https://github.com/kai1303/space/commit/58b2592)
- **Previews and developer coverage.** The launch page and workspace demo were updated alongside a standalone Tesser prototype. Gallery, browser, and integration coverage was added for uploads and queued sends, Office files, shared pins, mobile interactions, agent queues, and memory indexing. [Launch and prototypes](https://github.com/kai1303/space/commit/659aa37) · [Upload recovery coverage](https://github.com/kai1303/space/commit/33c456d)

### Still local

Each entry below describes work present in the checkout beyond `6b37add`. Links point to the working files. Some features are still being wired together.

#### Messaging, files, and navigation

- **Encrypted DMs and attachments.** Opt in to end-to-end encryption for new messages in a one-to-one or self DM. Verify devices, link or revoke a device, search decrypted history locally, and send encrypted files and images. Earlier messages retain their original protection. New encrypted messages currently support neither scheduled sends nor thread replies. [Encrypted DM behavior](docs/architecture/encrypted-dms.md)
- **Custom sidebar sections.** Work in progress adds named, collapsible personal sections and actions to organize channels and DMs within them. [Section contracts](packages/contracts/sidebar-sections.ts) · [Sidebar dialog](apps/web/src/features/channels/SidebarSectionDialog.tsx)
- **Pasted links and source navigation.** The composer recognizes URLs in pasted text. Following an agent’s message citation can load older history, center the cited message or reply, and take the reader back to the answer. [Pasted links](packages/ui/src/composer/pasted-links.ts) · [Source navigation](apps/web/src/features/chat/ChannelRoom.tsx)
- **PDF questions with page citations.** Agents receive an excerpt from an attached text-based PDF and can request other physical pages during the turn. Selecting a page citation opens the original at that page. Scanned pages need a text layer. [PDF reading](docs/architecture/agent-sessions.md#pdf-attachments)
- **Office edit review.** Ask Space AI shows the original passage and its proposed replacement. Request another revision or explicitly apply the edit. The plugin checks that the passage still matches before replacing it. [Office review](apps/web/src/features/files/OfficeAgent.tsx)

#### Knowledge and desktop

- **Automatic cross-channel decision search.** The configured knowledge provider indexes eligible human discussions across active channels by default. An agent can explain a decision and cite the discussion when the requester and the answer’s audience have access. [Channel discussions](apps/mcp-gateway/providers/pg-knowledge/README.md#channel-discussions)
- **Attachment search for agents.** Find a shared channel attachment by filename or type and return a link to the original. Access is checked for the people who will see the answer. [Attachment entities](apps/mcp-gateway/providers/pg-knowledge/README.md#attachment-entities)
- **Desktop plugin management.** Enable or remove the bundled Office editor and Web Browser independently for each Space account and server on a Mac. Opening a tool for the first time offers to install and open it. [Workspace panel](apps/desktop/README.md#workspace-panel)
- **Private browser Sidekick.** **Ask my agent** starts or resumes a private session for the current browser tab. Each turn carries the current page address with query parameters and fragments removed. The agent can use its owner’s personal MCP grants. **Control tab** remains the separate page-control action. [Browser Sidekick](apps/web/src/features/agents/BrowserSidekick.tsx) · [Tool access](docs/architecture/outbound-mcp.md)

#### Agent sessions and review

- **Persistent session goals.** Set and edit a goal for supported Codex and Claude sessions and deliver it to the connector. Codex also exposes pause and resume. [Goal controls](apps/web/src/features/agents/AgentSessionComposer.tsx) · [Goal contract](packages/contracts/session-goal.ts)
- **Provider-backed model and effort settings.** Choose from models reported by the paired provider and pass supported settings with the turn. Kiro exposes model selection through its CLI and currently reports no reasoning-effort control. [Composer settings](apps/web/src/features/agents/AgentSessionComposer.tsx) · [Connector details](apps/connector/README.md)
- **Inline code review and pull-request links.** Comment on lines of a reported patch and submit the comments to the agent. Coding connectors can also expose a configured HTTPS pull-request or branch-comparison page after a turn produces changes. [Patch review](apps/web/src/features/agents/PatchReview.tsx) · [Connector configuration](apps/connector/README.md)
- **Team review rooms.** Invite teammates to discuss a session and share selected files, diffs, or previews with them. Reviewers can use a dedicated review page. [Team review](apps/web/src/features/agents/SessionTeam.tsx)
- **Helper-agent handoffs.** Work in progress lets a participant choose a collaborating agent, write a request, and select the context to pass into a linked helper session. [Handoff form](apps/web/src/features/agents/SessionAgentHandoff.tsx) · [Handoff integration checks](tests/integration/session-agent-handoff.test.ts)
- **Session discovery and sidebar organization.** Browse sessions across a workspace and filter by text, work status, archive state, agent, channel, or creator. Reorder sidebar sessions, archive with undo, and restore archived sessions from the browser. [Session browser](apps/web/src/features/agents/SessionDiscovery.tsx) · [Sidebar actions](apps/web/src/features/channels/WorkspaceChannels.tsx)
- **Session reports in chat.** The originating message or thread shows the session’s status, result, and a shortcut to its changes, preview, or files when available. [Session reports](apps/web/src/features/chat/SessionReports.tsx)

#### Reliability and operations

- **MCP gateway recovery.** The gateway can reconnect its PostgreSQL permission listener after an outage. It marks itself unavailable during recovery, aborts interrupted operations, and checks current permissions on new calls. [Gateway lifecycle](docs/architecture/outbound-mcp.md)
- **Shared provider catalog.** Desktop and the connector read Codex, Claude, and Kiro identifiers and commands from a common catalog. Pairing validates the selected provider against its descriptor. [Provider catalog](packages/contracts/local-providers.json)
- **Connector and client recovery.** The connector handles transient authentication service failures during token renewal. Channel settings prefer the latest permission revision, and session lists can load further pages while retaining already loaded sessions. [OAuth recovery](apps/connector/oauth.ts) · [Channel permissions](apps/web/src/features/channels/ChannelDetails.tsx) · [Session pagination](apps/web/src/features/agents/useAgentSessionList.ts)
