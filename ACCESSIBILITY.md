# Accessibility in Space

We want teammates to be able to read conversations, send messages, and follow agent activity using a keyboard or assistive technology in the web and macOS apps.

Space is in early development. Browser and screen reader compatibility has yet to be documented across these workflows. Channel huddles do not retain a transcript for participants to read afterward. [Huddle behavior](docs/architecture/channel-huddles.md)

If a barrier prevents you from completing a task, tell us where it happened and what you were trying to do. Browser or macOS app version, input method, and assistive technology are helpful when known. A written description is enough. [Report an accessibility barrier](https://github.com/kai1303/space/issues/new?template=accessibility.yml)
